# 룬 UI 기획서 (클라이언트)

> 본 문서는 **Unity 클라이언트**의 룬(Rune Tree) 화면(UI 표현·조작·상태 연동)을 다룬다.
> 룬의 **서버 권위 규칙·데이터 모델·API·에러코드**는 서버 기획서가 정본이며 여기서 복제하지 않는다:
> [서버 성장(직업·스킬·룬) 기획서](../../../docs/세부/growth-기획서.md) §5.4 · [API 통합](../../../docs/공통/api-통합.md) · [ErrorCode 통합 정의](../../../docs/공통/error-code-정의.md).
> 인벤토리에서 진입하며, [스킬 레벨업 UI 기획서](스킬-레벨업-ui-기획서.md)와 짝을 이룬다.

## 1. 개요

- **목적**: **계정 공용 버프**인 룬을 골드로 강화하는 오버레이 패널. 선행 룬을 해금해야 다음 룬을 열 수 있는 **트리 구조**(`rune_master.prereq_code`)를 시각화하고, 각 룬의 레벨/효과/다음 비용을 보여준다.
- **진입점**: **인벤토리 패널 → '룬' 버튼**(장비 슬롯 열 위). 스킬 패널과 동일하게 인벤토리 위(sortingOrder 110)에 겹쳐 뜬다.
- **대상**: **클라이언트(Unity) 전용**. 표현·입력·서버 요청만 담당하고, 해금·레벨·골드 차감은 서버(GameServer)가 확정한다(서버 권위). 룬은 **캐릭터가 아니라 계정 단위**이므로 캐릭터 선택이 없다.
- **범위 경계**: 룬 업그레이드(해금 포함)만 다룬다. **룬 초기화는 미지원**(기획서). 스킬/액티브 장착은 별도 화면.
- **관련 기획서**: [서버 성장 기획서](../../../docs/세부/growth-기획서.md) §5.4, [마스터 데이터 기획서](../../../docs/세부/master-data/master-data-기획서.md)(`rune_master`·`rune_cost`).

## 2. 기능 설명 (사용자 관점)

- 상단 **상세 패널**: 선택한 룬의 아이콘 타일·이름·`레벨 x/max`·효과(전체 히어로 <스탯> +N%)·**다음 레벨 골드 비용**·**레벨업 버튼**. 좌상단에 보유 골드 표시.
- 하단 **룬 트리**: 선행 관계로 이어진 노드들(연결선). 각 노드는 스탯 계열별 색, `현재/최대` 레벨 배지, 선행 미해금 시 **잠김** 표시. 노드를 클릭해 선택하면 상세 패널이 갱신된다.
- **레벨업**은 선택 룬의 다음 레벨 골드 비용을 소모한다(0→1은 해금). 선행 룬이 레벨 1 이상이어야 상위 룬을 해금할 수 있다.
- 룬은 계정 공용 버프라 전 캐릭터(3인 파티) 전투력에 함께 적용된다.

## 3. 요구사항

- (F1) 인벤토리의 '룬' 버튼으로 `UIManager.Show(PanelType.Rune)` 진입, 닫기/딤으로 닫는다.
- (F2) `rune_master`(prereq·maxLevel·statType/statValue·레벨별 `costs`)로 트리를 구성한다. 깊이(선행 체인)별 행으로 배치하고 자식→선행을 연결선으로 잇는다.
- (F3) 현재 레벨은 세션 `runes`(`RuneDto`)에서, 보유 골드는 `currencies`(type 1)에서 읽는다. 다음 비용은 `costs[cur+1]`(= 서버 `rune_cost`와 동일값).
- (F4) 레벨업 버튼은 **비최대 && 선행 해금 && 골드 충분**일 때만 활성. 클릭 시 `POST /api/game/growth/rune/upgrade`, 성공하면 `/api/game/load` 재로드 후 UI·전투 갱신(`RaiseInventoryChanged`).
- (F5) 서버 오류(선행 미충족 5010·최대 5011·골드 부족 4005)는 하단 안내로 한글화(`ErrorMessages`).

**비기능**: 서버 권위(버튼 활성/비용은 힌트, 성립은 서버 확정), 중복 요청 방지(`_busy`).

## 4. 화면 구성 / 스크립트

- 캔버스: `ScreenSpaceOverlay`, `sortingOrder=110`, 기준 1080×1920. UI 스프라이트는 인벤토리 공용.
- 룬 전용 아이콘 에셋은 없어 **스탯 계열별 색 타일 + 이름/레벨 텍스트**로 노드를 표현한다.
- `Assets/Scripts/UI/RunePanelController.cs`(asmdef `TaskbarHero.Client.UI`) — 계층 생성·트리 배치·세션 바인딩·서버 연동.
- `Assets/Editor/RuneUiBuilder.cs` — 메뉴 **TaskbarHero/UI/룬 패널·씬 생성**(프리팹 + Title/GameScene UIManager 배선, EventSystem은 만들지 않음).
- 진입점: `InventoryPanelController`의 '룬' 버튼(`OnOpenRunePanel`).

## 5. 상호작용 흐름

1. 인벤토리 → '룬' → `Show(Rune)` → `OnEnable` → `RefreshFromSession()`(골드+트리+상세).
2. 노드 클릭 → 선택 → 상세 갱신(트리 하이라이트 재적용).
3. 레벨업 → `rune/upgrade {runeCode}` → 성공 → 재로드 → 트리/상세/골드 갱신 → `RaiseInventoryChanged()`.
4. 실패 → `ErrorMessages.ToKorean(error)`를 하단에 표시.
