# 클라이언트 문서

이 폴더(`com2us-taskbar-hero-client/docs`)는 **Unity 클라이언트 전용 문서**를 담는다.

## 문서 분리 원칙

- **클라이언트 문서는 여기(`docs/`)에서 작성·관리한다.** 씬 구성, UI 흐름, 클라이언트 아키텍처, 에셋 컨벤션, 로컬 상태 관리 등.
- **서버 프로젝트 문서(`../docs/`, 즉 `com2us-taskbar-hero/docs`)는 서버 연결이 필요한 경우에만 참조한다.** API 스펙(`공통/api-통합.md`), 에러 코드(`공통/error-code-정의.md`), 기획서(`세부/*.md`) 등은 클라이언트에서 복제하지 말고 원본을 참조한다.

## 문서 목록

- [클라이언트 씬 / 오브젝트 / UI 구성](클라이언트-씬-UI-구성.md) — 클라이언트가 구현할 씬·게임오브젝트·UI 화면의 큰 그림(서버 도메인 4.1~4.10 대응)
