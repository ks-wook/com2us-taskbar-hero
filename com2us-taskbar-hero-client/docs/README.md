# 클라이언트 문서

이 폴더(`com2us-taskbar-hero-client/docs`)는 **Unity 클라이언트 전용 문서**를 담는다.

## 문서 분리 원칙

- **클라이언트 문서는 여기(`docs/`)에서 작성·관리한다.** 씬 구성, UI 흐름, 클라이언트 아키텍처, 에셋 컨벤션, 로컬 상태 관리 등.
- **서버 프로젝트 문서(`../docs/`, 즉 `com2us-taskbar-hero/docs`)는 서버 연결이 필요한 경우에만 참조한다.** API 스펙(`공통/api-통합.md`), 에러 코드(`공통/error-code-정의.md`), 기획서(`세부/*.md`) 등은 클라이언트에서 복제하지 말고 원본을 참조한다.

## 문서 목록

- [클라이언트 씬 / 오브젝트 / UI 구성](클라이언트-씬-UI-구성.md) — 클라이언트가 구현할 씬·게임오브젝트·UI 화면의 큰 그림(서버 도메인 4.1~4.10 대응)
- **[ui/](ui/)** — UI 화면·패널 상세 기획서 모음
  - [인벤토리 UI 기획서](ui/인벤토리-ui-기획서.md) — GameScene에서 UIManager로 On/Off하는 인벤토리/장비 오버레이 패널(표시·장착/해제 조작, 서버 인벤토리 도메인 4.4 대응)
  - [스킬 레벨업 UI 기획서](ui/스킬-레벨업-ui-기획서.md) — 인벤토리에서 진입하는 캐릭터 스킬 레벨업/초기화 오버레이 패널(캐릭터 레벨 파생 스킬포인트, 서버 성장 도메인 4.5 대응)
  - [룬 UI 기획서](ui/룬-ui-기획서.md) — 인벤토리에서 진입하는 계정 공용 룬 트리 오버레이 패널(선행 해금·골드 강화, 서버 성장 도메인 4.5 대응)

_새 클라이언트 시스템을 설계·구현할 때 이 폴더에 문서를 추가하고 이 목록에 링크한다._
