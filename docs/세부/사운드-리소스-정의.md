# 사운드 리소스 정의서

Taskbar Hero 모작 클라이언트에 필요한 **BGM·효과음(SFX) 목록**을 현재 구현된 씬·스크립트·마스터 데이터 기준으로 정리한 문서다.
"어떤 소리가 몇 개 필요한가"를 확정하기 위한 **에셋 요구사항 명세**이며, 재생 코드(AudioManager)·씬 배선 등 실제 구현은 클라이언트 작업 범위다.

- 기준 커밋: `c2a4ce0`(출석부 기능 추가) 시점의 `com2us-taskbar-hero-client/`
- 참조: [스테이지·전투 기획서](stage-battle-기획서.md) · [성장 기획서](growth-기획서.md) · [인벤토리/아이템/큐브 기획서](inventory-item-cube-기획서.md) · [출석 기획서](attendance-기획서.md) · [메일 기획서](mail-기획서.md) · [오프라인 보상 기획서](offline-reward-기획서.md)

## 1. 현재 상태

| 항목 | 상태 |
| --- | --- |
| 보유 사운드 에셋 | `Assets/Sound/sword_swing.mp3` **1개뿐** |
| 사운드 재생 코드 | **없음** — `AudioSource`·`AudioClip`·`PlayOneShot` 참조가 스크립트·씬·프리팹 전체에서 0건 |
| 오디오 믹서/볼륨 설정 | 없음 |

즉 **재생 계층 자체가 아직 없다.** 에셋 확보와 별개로 `Assets/Scripts/Managers/SoundManager.cs`(싱글턴 + BGM 1채널 크로스페이드 + SFX 풀) 신설이 선행돼야 한다(→ [7. 구현 메모](#7-구현-메모)).

## 2. 규칙(제안)

### 2.1 폴더 구조

```
Assets/Sound/
├── BGM/                      # 배경음(루프)
├── Jingle/                   # 짧은 비루프 연출음(클리어·패배)
└── SFX/
    ├── UI/                   # 버튼·패널·모달 공통
    ├── System/               # 로그인·씬 전환·알림
    ├── Battle/
    │   ├── Common/           # 피격·사망·레벨업·보상
    │   ├── Knight/           # 기사 기본공격·스킬
    │   ├── Archer/           # 레인저
    │   ├── Mage/             # 마법사
    │   └── Monster/          # 몬스터·보스
    └── Growth/               # 인벤토리·스킬·룬·큐브·메일·출석
```

### 2.2 네이밍

- 소문자 스네이크 케이스 + ASCII만 사용: `bgm_title`, `sfx_knight_shield_charge`
- 접두사: `bgm_` / `jingle_` / `sfx_`
- 2단 구성 연출(발동 → 명중)은 `_cast` / `_impact` 접미사로 분리: `sfx_mage_fireball_cast`, `sfx_mage_fireball_impact`

### 2.3 포맷

| 종류 | 포맷 | Unity Import 설정 | 길이 기준 |
| --- | --- | --- | --- |
| BGM | `.ogg` (Vorbis) | Streaming, Load in Background | 60~120초 루프 |
| 징글 | `.ogg` | Compressed in Memory | 2~5초 |
| SFX | `.wav` 16bit 44.1kHz | Decompress on Load(짧은 것) / ADPCM | 0.1~1.5초 |

### 2.4 볼륨 카테고리

`Master` / `BGM` / `SFX` 3채널. **이 게임은 작업표시줄에 상주하는 항상-위 소형 창**(`TaskbarWindow.cs`)이라 장시간 켜두는 사용 패턴이므로:

- 기본 마스터 볼륨을 낮게(0.4~0.5) 잡는다.
- 창 포커스 아웃 시 자동 감쇠/뮤트 옵션을 권장한다.
- BGM은 반복 청취 피로가 적은 저자극 톤으로 고른다.

## 7. 구현 메모

### 7.1 선행 작업 — SoundManager 신설

- 위치: `Assets/Scripts/Managers/SoundManager.cs` (`TaskbarHero.Client.Managers`, 매니저 클래스 규칙 준수)
- 구조: `DontDestroyOnLoad` 싱글턴 + **BGM 2채널 크로스페이드** + **SFX AudioSource 풀**(동시 발음 8~12개)
- 클립 참조: `[SerializeField]` 배선(프로젝트 규칙상 `Resources.Load` 지양) 또는 SFX ID → 클립 매핑 ScriptableObject(`ItemIconDatabase.asset`·`SkillIconDatabase.asset`과 동일한 패턴)
- 스킬 SFX는 `PartyMemberConfig`의 `EffectFor(skillCode)`처럼 **스킬 코드 → 클립** 매핑을 두면 이펙트 배선과 대칭이 된다.

### 7.2 동기화 주의 지점

| 지점 | 주의 |
| --- | --- |
| 스킬 발동 vs 데미지 | `PlayerCombatant.CastSkill()`은 이펙트 재생 후 `DealDamageAfter(motion, ...)`로 데미지를 지연시킨다. 발동음과 임팩트음을 나눌 경우 임팩트음은 이 지연 콜백에 붙인다. |
| 투사체 | `ProjectileEffect.Launch()` / `ArrowProjectile.Launch()`의 **도달 콜백**이 명중 시점이다. |
| 슬로우모션 | 클리어·패배 연출은 `Time.timeScale = 0.25`로 진입하고 UI는 `unscaledDeltaTime`으로 재생한다. 오디오는 `AudioSource.pitch`가 timeScale의 영향을 받지 않으므로 그대로 두면 되지만, `WaitForSeconds` 기반 사운드 스케줄링은 `WaitForSecondsRealtime`으로 맞춰야 한다. |
| 광역 스킬 | `DealAreaDamageAfter()`는 대상 수만큼 루프를 돈다. 피격음을 대상마다 재생하면 겹쳐서 찢어지므로 **프레임당 1회로 제한**한다. |
| 몬스터 다수 | 웨이브당 최대 12마리가 동시 사망할 수 있다. 동일 SFX 동시 재생 쿨다운(0.05초)을 둔다. |

### 7.3 라이선스

과제 제출물이므로 상용 배포 제약이 없는 소스로 확보한다(CC0 / Kenney / freesound CC0 등). 확보처와 라이선스는 에셋 추가 시 이 문서 하단에 기록한다.
