# com2us-taskbar-hero

2026 컴투스 지니어스 - 방치형 게임 **Taskbar Hero** 모작 프로젝트 서버

- **AccountServer** — 계정/인증 서비스 (`http://localhost:5160`, `https://localhost:7110`)
- **GameServer** — 게임 로직 서비스 (`http://localhost:5247`, `https://localhost:7179`)
- **TaskbarHero.Common** — 서버-클라 공유 라이브러리 (`netstandard2.0`, Unity UPM 패키지로도 소비)

전체 개발 로드맵은 [docs/서버-개발-계획.md](docs/서버-개발-계획.md)를 정본으로 한다. 아래 현황판은 그 **주차별 일정**을 기준으로 서버/클라 작업 진척을 추적하기 위한 체크리스트다.

## 개발 현황 (2026-07-20 ~ 08-21)

> **트랙 구분** — 서버(ASP.NET Core)와 Unity 클라이언트는 **병행 개발**한다. 각 기능은 API 계약(요청/응답 스키마·공유 DTO·`ErrorCode`)을 먼저 확정하고, 클라는 목(mock)으로 선행 개발한 뒤 서버 구현 완료 시 **실연동**으로 교체한다.
>
> **체크 항목** — `서버`: 서버 구현 완료 · `클라`: 클라 실연동 완료

> <!-- 완료 시 삭제 --> **인벤토리 / 아이템 / 큐브**: 인벤토리/아이템 액션 중 **장착·장착 해제·배치 이동·용량 확장(equip·unequip·move·expand)** 서버 구현 완료. **강화(enhance)·랜덤 상자(box, 뽑기)·큐브(합성/분해/제작)** 는 미구현(강화·뽑기는 별도 백로그, 강화는 `enhance_master` 값 대기).
>
> <!-- 완료 시 삭제 --> **성장(직업·스킬·룬)**: 스킬 레벨업·초기화·액티브 장착·룬 업그레이드(`growth/skill/levelup`·`skill/reset`·`skill/equip`·`rune/upgrade`) 서버 구현 완료. 스킬 포인트는 `level_master.skill_points`에서 파생, 룬 비용은 `기준값 × 목표 레벨`로 서버 산출. 전직은 미지원(범위 밖). **클라: 스킬 레벨업 UI(`SkillPanel`) + 룬 트리 UI(`RunePanel`, 인벤토리 → '스킬 레벨업'/'룬' 진입) 구현 및 실서버 연동 검증 완료. 스킬: 레벨업/포인트부족(5003)/초기화 E2E 통과. 룬: 계정 공용 골드 소모 트리(선행 해금)로 루트 해금→상위 해금(rune_cost 명시값 차감)→선행미충족(5010) E2E 통과. 액티브 스킬 장착 UI만 후속(◐ 유지).**
